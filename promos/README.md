# Plugin Store promo images

Marketing images for the Friend listing on the Craft Plugin Store, rendered in the same family
theme as the plugin's marketing page at
[justinholt.com/plugins/craft-friend](https://justinholt.com/plugins/craft-friend).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `friend-promo-N.jpg`, 1920×1080. Headless Chrome renders each slide at
2× and can only write PNG, so `build.sh` downsamples and converts to JPEG (quality 90) in one
`sips` pass and deletes the PNG. **Promos ship as JPEG, never PNG**: `out/` should hold only
`.jpg` files.

Chrome sometimes exits non-zero from its teardown watchdog after the screenshot is already on
disk, so `build.sh` judges each slide by whether the PNG was written, not by Chrome's exit code.

against the plugin-testing harness, the same URLs that appear in the slide 7 log.

## Screenshots

`shots/` holds the two control-panel captures, taken from the plugin-testing harness with
`~/Sites/plugin-shots`:

```bash
cd ~/Sites/plugin-shots
node capture.mjs ~/Sites/craft-friend/promos/shots specs/friend.json
```

The log rows came from real requests (`curl` against dead URLs on the harness site), so the
redirects, scores and rule names in the screenshot are what Friend actually decided. The log
capture (`?sort=hits&status=redirected`) is a full page; the slide clips it in CSS (`.cpc-clip`) to the six rows seeded for it, which keeps rows left by other plugins' tests on the shared harness out of frame.

## Editing

Everything lives in `slides.html`, one `<section class="slide">` per image. Accent `#0EA5E9`
(sky), Jersey 20 for display, Inter for body.

`assets/` holds the fonts and two icon files:

- `icon.svg`: a byte-identical copy of `../src/icon.svg`, used for the cover mark and the footer
  lockup. Copy it again whenever the icon changes.
- `watermark.svg`: the glyph from `../src/icon-mask.svg` alone, filled white, with no tile. The
  tiled app icon reads as a hard-edged box at watermark scale.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.
